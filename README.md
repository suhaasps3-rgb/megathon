# PaisaPath — Cache me if you can

Financial-literacy app (Vite + React + Tailwind) with Life Mode, a playable 3D neighborhood, an AI/offline mentor and audio mode.

    npm install
    npm run dev       # local app
    npm run check     # typecheck + tests + build

Optional: set `VITE_GEMINI_API_KEY` in a local `.env` (never committed). Without it the app uses an offline mentor.

Deliverables (M1, M2 report) are in `deliverables/`.
